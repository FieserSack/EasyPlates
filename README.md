# EasyPlates

Custom nameplates for **World of Warcraft 3.3.5a** (Wrath of the Lich King, Interface `30300`).

Developed for Rising Gods / classic WotLK clients.

## Features

- Custom health bars with reaction colors
- Target highlight (border color)
- Threat percentage
- Cast bar with spell icon (full plate width)
- Buffs / debuffs under the health bar (TargetFrame-style stealable overlay & debuff type borders)
- Raid target icon (left of name + health)
- Elite / rare icon and level
- Options under **Esc → Interface → AddOns → EasyPlates**

## Install

1. Copy the `EasyPlates` folder to  
   `World of Warcraft/Interface/AddOns/EasyPlates`
2. Restart the client or `/reload`
3. Enable the addon at character select
4. Show enemy nameplates (**V**)

## Commands

| Command | Action |
|---------|--------|
| `/ep` or `/easyplates` | Open options |
| `/ep reset` | Reset settings |
| `/ep scan` | Rescan nameplates |
| `/ep debug` | Detection diagnostics |

## Requirements

- Client build **3.3.5a** (12340)
- Interface version **30300**
